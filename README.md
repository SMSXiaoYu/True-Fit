# TrueFit 简旨

> 给简历捡旨（减脂）。

## 一句话介绍

不编造、不美化，只把已有的真实履历，排到最该被看到的位置。

## 背景与痛点

- 简历优秀，却海投杳无音信
- 履历丰富，却要为每个岗位（JD）逐一调整，费时费力
- 现有工具要么「无脑美化」（容易捏造、面试一问就穿帮），要么只「打分」（不解决排版与表达）
- **TrueFit 的核心解法**：通过大模型深度理解 JD 与简历，提炼出带量化指标的业务战役（Bulletins），每一句都可精准溯源回原文，做真正的“简历瘦身”。

## 核心理念

- **不编造、可溯源**：每条 AI 输出都能点回原文，甚至精确到“单句级”高亮对照，用户敢投，面试敢用。
- **只做减法，不新增事实**：完整原始简历是唯一事实源，被过滤的废话会在原文用 `(未采用)` 折叠提示。
- **人始终有最终决定权**：系统给的只是草稿，用户可以在第4步自由修改、删除、拖拽，甚至**手动添加**新的经历或要点。

## 产品形态与亮点

- **输入**：完整简历（PDF / Word / Markdown / TXT / 粘贴文本）+ JD
- **两种模式**：
  - **一键生成（直通第6步）**：系统自动完成提取、聚类、切分、排版，直接呈现最终简历纸。
  - **自己给简历瘦身（逐步确认）**：走完 3/4/5 步，用户在每一环节都有极强的掌控感。
- **颗粒度选择**：
  - **【句组】（核心杀手锏）**：按业务动作切分为多条干练的 bullet points，完美贴合真实简历格式。
  - **句子 / 段落**：兼顾极简与快速。

## 核心功能一览

| 功能模块           | 说明                                                                 |
| -------------- | ------------------------------------------------------------------ |
| **业务战役级提炼**    | 调用1（v9版）直接过滤废话，将零碎动作合并为“动词 + 技术 + 量化指标”的长句。                        |
| **句组智能重组**     | 调用X 结合 JD 把战役句切分为干练的 Bulletins，保留技术名词，绝不遗漏 300ms、QPS 等指标。          |
| **精准双向溯源**     | 悬停瘦身简历，左侧原文精准高亮（精确到句，不亮整段）；未被采用的原句以浅灰色折叠展示。                        |
| **双层“添加”体验**   | 用户可在顶部添加“整段经历”，也可在卡片内添加“单条要点”，自动打上 `✨ 用户添加` 标识。                    |
| **非破坏性重置**     | 点击“全部重置”只抹除 AI 生成部分的修改（恢复初始），绝不删除用户自己添加的心血。                        |
| **Word 沉浸式导出** | 导出前先进入网页预览，可下载为标准 `.docx`。保留极简商务风排版（隐藏表格对齐），方便用户自己补充敏感信息（电话/真实姓名）。 |
| **会员版导出（预埋）**  | 菜单中已预埋“无水印 PDF”、“Word 导出”的 VIP 标识入口。                               |

## 技术架构

```
┌─────────────────┐         ┌─────────────────────┐         ┌──────────────────┐
│  index_live.html │  HTTP   │     server.py       │  内部   │  src/pipeline/   │
│   （前端单文件）  │ ──────> │  （Flask Web 服务）  │ ──────> │  （Pipeline）     │
└─────────────────┘         └─────────────────────┘         └──────────────────┘
                                     │                                │
                                     ▼                                ▼
                            data/jobs/{job_id}/              src/prompts/ (LLM prompts)
                            （每次上传独立产物）               .env (DEEPSEEK_API_KEY)
```

### 前端（`index_live.html`）

单文件（HTML + CSS + JS），包含完整的交互状态机：

- **上传锁定态**：生成过简历后，输入框自动锁定防误触。可点击右上角或底部的“新建简历瘦身”开启全新任务。
- **第4步核心编辑器**：卡片内支持行内编辑、拖拽排序、删除、重置；支持精准原文高亮联动。
- **第6步排版预览**：支持连续/分页、页内/全屏审阅，支持 PDF 截图渲染、Word 纯净模板渲染。

### Pipeline（核心调用链）

新版架构实现了“业务提炼 + 精准切分”的双引擎：

```
简历 + JD
  ↓
[调用1] 简历提炼（v9 业务战役版，强制合并长句，提取粗粒度 W1/P1） 
[调用2] JD提炼
  ↓
[调用3/4] 打分与分层
[调用U] 自动聚类（按业务主题分组）
  ↓
[调用X] 句组切分（结合 JD 过滤，精准映射句子级 W1_L3，产出 bulletins.json）
  ↓
[调用5] (仅 sentence/paragraph 模式备用，bulletin模式直接跳过) 
[环节G] Gate 校验
  ↓
[调用6] 匹配报告 + [调用7] 完整简历组装
```

*注：LLM 只输出结构化指令或要点，绝不无中生有；匹配报告和组装完全由本地规则执行。*

### 数据层与防编造机制

- **Source Mapping**：每一条改写或切分出的句子，背后都绑定了严格的 `source_ids`。人工手改的句子会自动解除映射，打上标识。
- **Gate 校验**：包含 4 道门禁（来源存在性、公司/时间不可篡改、操作在枚举内、数字名词一致性），在非直接切分的模式下提供强力兜底。

## 项目结构

```
True-Fit简旨/
├─ index_live.html     # 前端（单文件，Live数据版）
├─ server.py           # 后端（Flask 服务，处理指纹与任务调度）
├─ docs/               # 设计文档（产品设计、Pipeline、算法说明等）
├─ data/jobs/          # 每次任务的独立产物缓存（按指纹生成）
├─ src/
│  ├─ prompts/         # 所有的 LLM 提示词（包含调用1_v9, 调用X 等）
│  └─ pipeline/        # 核心管线代码
├─ requirements.txt
└─ .env.example        # 密钥配置示例
```

## 快速开始

1. **安装依赖**：`pip install -r requirements.txt`
2. **配置环境**：复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`（或配置 Ollama 本地模型）。
3. **启动后端**：`python server.py`（等待控制台显示 bge-m3 预热完成）。
4. **启动前端**：浏览器直接打开 `index_live.html`，或访问 `http://localhost:8000/live`。

### 体验步骤：

1. 上传示例简历与 JD（或自行上传）。
2. 在配置弹窗中，确认颗粒度选择为\*\*【句组（智能重组）】\*\*。
3. 点击【一键生成瘦身简历】（首次跑需等待约 1.5 - 2 分钟大模型工作）。
4. 在完成页，你可以尝试 **导出 PDF**，或者 **导出为 Word 文档**。
5. 回退到第 4 步，体验精准高亮溯源、拖拽重排，以及手动 **添加/修改** 经历。
