## 2. 首页

**元素：**
- 上传简历（PDF/Word/Markdown/Txt，或粘贴文本）
- 上传JD（同上）
- 底部居中，两个按钮同一行：
  - **【一键生成瘦身简历】**（主按钮，更大/主色/带投影）
  - **【自己给简历瘦身】**（次按钮，次要样式）
- 【进入瘦身配置】按钮（顶栏右侧，展开/收起抽屉）

**两个按钮的灰色逻辑（相同）：**

| 状态 | 按钮 | 提示 |
|---|---|---|
| 资料没传完 | 灰色 | “请先上传完整的Resume和JD” |
| 资料传完，从未生成过 | 可点 | — |
| 配置已展开，从未生成过，未调参 | 灰色 | “调整参数后可生成” |
| 已按当前参数生成过，未调参 | 灰色 | “已按当前配置瘦身” |
| 调参后 | 重新可点 | — |

**“调参”定义：** 勾选/取消维度、滑动权重、切换预设。
仅展开/收起抽屉，未做任何操作 → 不算调参。

**两个按钮的区别：**
- 【一键生成瘦身简历】→ 模式B（系统自动选择+自动聚类）
- 【自己给简历瘦身】→ 模式A（用户自定义选择+聚类）

**生成按钮状态机（含已生成态）：**

| 状态 | 按钮名 | 行为 |
|---|---|---|
| 未传完 | 一键生成瘦身简历（灰） | 不可点 |
| 从未生成 | 一键生成瘦身简历（主色） | 生成 |
| 已生成，输入没变 | 查看已瘦身的简历（次色） | 回结果页 |
| 已生成，输入变了 | 一键生成瘦身简历（主色） | 重新生成 |

**输入变化 = 简历变了 / JD变了 / 配置变了。**

## 3. 配置面板（右侧抽屉）

**布局：**
- 抽屉从右侧滑出，宽360px
- 不离开首页上下文，左侧页面仍可见

**触发：**
- 点【进入瘦身配置】→ 展开抽屉
- 再点一次 → 收起

### 3.1 维度勾选

**四个维度：** 技能 / 内容 / 行业 / 资历

**默认状态：** 全勾选

**交互规则：**
- 勾选 → 权重滑块可用
- 取消勾选 → 对应权重滑块置灰（不隐藏），权重值保留
- 重新勾选 → 权重恢复原值

### 3.2 权重滑块

**用户调整的是分数（0-100），百分比自动计算、只读。**

**默认分数：** 技能20 / 内容45 / 行业15 / 资历10（总和90）

**默认百分比（只读）：**
- 技能 22% / 内容 50% / 行业 17% / 资历 11%

**交互规则：**
- 滑块可拖（0-100）
- 数值可直接输入（0-100）
- 两者联动
- 百分比 = 该维度分数 / 所有已勾选维度分数之和，自动算
- 分数为0时，百分比显示0%

**分数为0 vs 取消勾选：**
- 分数=0：滑块正常，数值为0，维度仍“已勾选”
- 取消勾选：滑块置灰，权重值保留
- 两者对结果影响相同（都不参与打分）

### 3.3 预设系列

**六个选项：**

| 选项 | 分数 | 说明 |
|---|---|---|
| 系统自动判断 | — | LLM分析JD，选出最接近的预设，静默选中 |
| 通用 | 20/45/15/10 | 固定 |
| 技术 | 30/30/10/30 | 固定 |
| 管理 | 20/35/10/35 | 固定 |
| 校招 | 30/30/5/5 | 固定 |
| 用户自定义 | 可编辑 | 从当前预设继承分数，可自由调整 |

**默认行为：** 系统自动判断 → 落到某个固定预设（静默，不解释）

**用户可改：** 手动选其他预设，或切到【用户自定义】

**固定预设：** 分数不可编辑，滑块置灰
**用户自定义：** 分数可编辑，滑块变亮

**重要规则：** 用户一旦动手调参（勾选/滑杆/数字），预设自动切为【用户自定义】。

### 3.4 抽屉内生成入口

抽屉底部吸底放置【生成瘦身简历】按钮 + 状态提示行，其可用状态与首页主按钮**完全同步**；点击后自动收起抽屉并执行生成。

**布局：上方两栏 + 下方匹配报告**

┌──────────────────────────────────────┐

│ （各自独立滚动） │  
│ │  
└──────────────────────────────────────┘  
┌──────────────────────────────────────┐  
│ 📊 匹配报告 │

### 4.1 上方两栏

| 栏位 | 内容 |
|---|---|
| 左 | 简历原文（只读，用于对照溯源） |
| 右 | 瘦身简历（预览态/编辑态，可导出） |

**比例：** 原文 : 瘦身简历 = 1 : 3

**滚动：** 两栏各自独立滚动，栏头 sticky 吸顶

### 4.2 悬停高亮（双向溯源）

- 悬停瘦身简历句子 → 左侧原文对应片段高亮
- 悬停左侧原文片段 → 瘦身简历引用该片段的句子高亮
- 点击瘦身简历句子 → 左侧滚动定位到来源片段
- 点击匹配报告改动条目 → 同时高亮原文 + 瘦身简历对应位置
- 用户手改的句子标记 `user_edited`，不参与联动

### 4.3 匹配报告（底部）

**默认折叠状态：**
- 📊 匹配报告
- 总体匹配分（如 67/100）
- 一句话结论（模板生成，不调LLM）
- 按钮：【查看完整匹配报告】

**点【查看完整匹配报告】后展开，显示完整内容：**

**匹配报告：**
- 总体匹配分
- 一句话结论
- 四维度分数（技能/内容/行业/资历）
- 命中项（JD要求 → 简历证据）
- 缺口项（JD要求但简历未体现）

**改动说明：**
- 每条改动的操作类型 + 经历名 + 说明
- 操作类型：verbatim / compress / reword / merge / reorder / demote / omit

**补充建议：**
- 编号列表，给出可执行的补强方向

**说明：** 匹配报告全部由规则+模板生成，不调用LLM。

## 5. 编辑页（核心）

### 5.1 总流程

系统提取核心的、不重复经历 → 按相关性排序 → 用户选择 → 加工成最终简历。

### 5.2 卡片列表

**每张卡片显示：**

| 项 | 内容 | 说明 |
|---|---|---|
| 1 | 经历标题 | 如“订单中心重构” |
| 2 | 相关度分 | 灰色/注释形式，仅辅助，不进入最终简历 |
| 3 | 当前层级 | 核心内容 / 相关内容 / 其他内容 |
| 4 | 关键信息 | role + 前1-2条 actions |

**排序：** 初始按相关度分从高到低排序。

### 5.3 用户操作

**勾选：**
- 每张卡片可勾选（保留 / 不保留）
- 默认全部勾选

**删除与恢复：**
- 卡片可删除，删除后进入“已删除”区
- 可从“已删除”区恢复

**拖拽调序：**
- 拖拽卡片调整顺序

**合并（聚类）：**
两种交互都支持：
- **拖拽合并**：把一段拖到另一段上 → 两段合并成一组
- **勾选合并**：勾选多段 → 点【合并到一组】

**合并后：**
- actions / results 合并
- tech 去重
- 可撤销（反悔）

### 5.4 两种加工模式

**模式A：用户自定义**

1. 用户自主勾选需要的经历
2. 用户自主指定哪些经历放在一起（聚类）
3. 系统按用户的聚类，生成瘦身简历

**模式B：一键生成**

一期行为：
1. 系统自动选择所需经历（默认全部选中）
2. 每个经历 E 自成一组（group_title = E.title）
3. 系统按相关性分三层陈列

二期：
- 补上“自动聚类”（把同一业务主题的经历合并成一组）
- 标记为“待添加自动聚类功能”

**说明：** 自动聚类可能不稳定（LLM每次结果可能不同），用户不满意可切到模式A自己调。

### 5.5 最终输出：三层结构

无论模式A还是B，最终都输出三层结构的瘦身简历：

| 层级 | 篇幅 | 内容 | 阈值 |
|---|---|---|---|
| 核心经历 | 大 | 原文或由原文加工 | 相关分 ≥ 7 |
| 相关经历 | 中 | 只保留与JD相关的内容 | 4 ≤ 相关分 < 7 |
| 其他经历 | 小 | 只留必要叙述，去掉无关信息 | 相关分 < 4 |

### 5.6 两种模式的关系

| | 模式A 自定义 | 模式B 一键 |
|---|---|---|
| 选择经历 | 用户勾选 | 系统全选 |
| 聚类 | 用户手动 | 系统自动（按主题） |
| 输出 | 三层简历 | 三层简历 |
| 适合 | 想控制 | 想省事 |

**两个模式可互相切换：**
- 模式B生成后，可切到模式A继续调
- 模式A调整后，可回到模式B重新自动聚类

### 5.7 中栏编辑（原地编辑）

**预览态 → 编辑态：**

- 点中栏栏头【进一步编辑】→ 进入编辑态
- 中栏外轮廓变为蓝色虚线框
- 按钮变绿色【✓ 编辑完成】
- 顶部出现蓝色提示条

**编辑能力：**
- **行内改文字**：每个句子可改，改过的句首圆点变绿 + 标记 `user_edited`
- **解除映射**：人工改写的句子不再参与溯源高亮
- **拖拽排序**：按住经历卡片可拖动调序（SortableJS）
- **防丢失**：编辑态下若有未保存修改就关闭页面 → 弹离开确认

**退出编辑：**
- 点【✓ 编辑完成】→ 保存修改，退出编辑态，Toast 提示“已保存修改，瘦身简历已锁定预览”



### 5.8 导出

点中栏栏头【⬇ 导出】：

- **导出 Markdown**（`瘦身简历.md`）
- **导出纯文本**（`瘦身简历.txt`）

导出内容按当前三层分区结构组织，包含用户的文字修改。

### 5.9 完成

- 点【完成】→ 回结果页
- 编辑结果自动保存


## 6. 输出层：组装完整简历

### 6.1 问题

当前输出只有「改写后的经历」，用户还得自己拼基本信息、教育经历、技能清单，才能投递。

**目标：** 输出一份可直接投递的完整简历。

### 6.2 输出结构

```
完整简历
├─ 基本信息（原文照搬）
├─ 求职意向（原文照搬，可选）
├─ 教育经历（原文照搬）
├─ 技能清单（按 JD 相关性排序，不删）
├─ 核心经历（调用5改写后）
├─ 相关经历（调用5改写后）
└─ 其他经历（调用5改写后）
```

### 6.3 数据来源

| 字段 | 来源 |
|---|---|
| 基本信息 | 调用1产物的 basic_info |
| 求职意向 | 调用1产物的 intent |
| 教育经历 | 调用1产物的 education |
| 技能清单 | 调用1产物的 skills_declared，按 JD 排序 |
| 经历 | 调用5改写后的输出 |

### 6.4 组装方式

**纯规则拼接，不调 LLM。**

调用1 已经提取了这些字段，直接取即可。

### 6.5 技能排序规则

- JD 里出现的技能 → 排前面
- JD 里没出现的 → 排后面
- **不删任何技能**

排序依据：技能字符串匹配。

### 6.6 为什么不用 LLM

- 基本信息和教育经历：原文照搬，无需改写
- 技能清单：只需按 JD 排序，规则可完成
- 唯一需要 LLM 的「经历改写」已由调用5完成


## 7. 异常与边界处理

| 场景 | 处理 |
|---|---|
| 简历/JD 未传完 | 生成按钮禁用 + 琥珀色文字提示缺输入 |
| 浏览器拒绝读取剪切板 | 文本框聚焦并提示手动 Ctrl+V |
| 仅打开抽屉未操作 | 不算配置变更，不触发 changed 态 |
| 固定预设下尝试改权重 | 滑块/数字框禁用；先切「用户自定义」才可编辑 |
| 人工编辑后溯源 | 编辑句解除 source 映射，不参与高亮联动 |
| 人工编辑后看报告 | 报告不重算，栏头副标明确声明 |
| 编辑中刷新/关闭页面 | beforeunload 弹出离开确认 |
| 输入权重越界 | 数字框钳制在 0–100 |
| 被 omit 的经历 | 不渲染于中栏，但数据层保留，支持恢复 |

## 8. 状态与数据持久化

**sessionStorage 持久化：**
- 存储键：`tf-home`
- 保存字段：resume、jd、scores、checked、preset、generated、snapshot

**任何改变状态的操作都触发保存：** 上传、粘贴、编辑文本、清空、调权、勾选、生成完成。

**刷新或返回首页自动恢复：** 上传卡片、抽屉配置、生成按钮状态。

## 9. 5步流程：第3步、第4步、第5步

### 9.1 第5步：完成

**布局：**
- 三栏：左导航（可收起）、中简历纸、右操作说明（可收起）
- 操作栏5个按钮：【打开/收起导航】【⚙ 调整】【⛶ 审阅 ▾】【⬇ 导出 ▾】【打开/收起操作说明】
- 导航顶部显示"共 X 页"

**⚙ 调整面板：**
```
样式
├─ 标题对齐：[居中] / [左对齐]
├─ 标题大小：[滑块] [Spinner]
├─ 正文大小：[滑块] [Spinner]
└─ 模块分隔：[有横线] / [无横线]

视图
└─ 分页/连续：[分页查看] / [连续查看]
```

**⛶ 审阅：**
- 下拉菜单：【页内预览】【全屏预览】
- 页内预览：其他区域变底色，简历纸位置不变
- 全屏预览：Fullscreen API，中间简历纸，两侧黑屏
- 都支持：拖拽、滚动、zoom in/out、ESC退出

**分页逻辑：**
- 物理分页（每页独立容器，高度=A4）
- 分页线：`------ 第 X 页 / 共 N 页 ------`
- 分页规则：卡片不跨页 → 整卡挪下页 → 卡本身超一页按句号切 → 兜底按行切
- 标题不孤行：模块标题+次标题+第一个内容块，不跨页

**核心原则：审阅 = 导出**
- 页内预览、全屏预览、导出PDF，三者效果一致

**导出：**
- 导出PDF：SnapDOM + jsPDF，图片版PDF
- 导出Markdown
- 导出纯文本

**操作说明：**
```
1. 通过拖动 ⠿ 或左侧导航，调整模块顺序
2. 通过 ⚙ 调整，修改简历布局
3. 点击 👁 审阅，可选「页内预览」或「全屏预览」
4. 点击 ⬇ 导出，导出简历
5. 点击 🗑 删除，移除模块（可在上方"已删除"处恢复）
6. 如需修改简历内容，回到第3步或第4步编辑
```

### 9.2 第3步：确定核心经历 & 第4步：确定其他信息

**每个模块右上角：**【✎ 编辑】【↺ 重置编辑】【🗑 删除】

**【↺ 重置编辑】** 只在"编辑过"的模块显示。

**页面右上角：**【↺ 全部重置编辑】

**第3步标题：** 确定核心经历

**第3步底部：**【← 返回经历提取】
