## 1. 产品流程总览

六步流程（顶部流程条贯穿全部页面）：

```
1. 上传 → 2. 提取相关履历 → 3. 整理我的经历 → 4. 确定核心经历 → 5. 确定其他信息 → 6. 完成
```

- **第2步**是一次性加载页：提取完成后，点击流程条可回溯进入该页查看历史日志（回放模式）。
- 首页提供双生成入口：【一键生成瘦身简历】（模式B）/【自己给简历瘦身】（模式A），点击后均会弹出【瘦身配置】弹窗进行参数调整。
- **模式B（一键）**：自动确认第3/4/5步，直接落到第6步（完成）。
- **模式A（自己）**：走完第3/4/5步 → 进入第6步。

**顶部流程条规则：**

| 步骤状态 | 样式 | 可点 |
|---|---|---|
| 当前步 | 高亮 | — |
| 已完成步（到达过） | 正常色 | 可点跳转 |
| 未来步（未到达） | 灰色 | 不可点 |

## 2. 首页

**元素与状态：**

1. **上传卡片（Resume / JD）**：
   - 支持 PDF / DOCX / Markdown / Txt，或粘贴文本。
   - **输入锁定态**：只要点击生成（进入第2步），Resume 和 JD 即进入**锁定态**。顶部标签变为【已锁定】（琥珀色），隐藏上传、粘贴、编辑、清空、载入示例等所有操作按钮，预览框仅可滚动浏览，不可修改。
2. **【瘦身配置】弹窗**：
   - 点击生成按钮触发。包含：打分维度、预设系列、颗粒度、AI分组。
   - 底部操作按钮：【一键给简历瘦身】/【自己给简历瘦身】/【取消】。
3. **生成按钮状态机**：
   - **未传完**：单个居中按钮【开始给简历瘦身】（灰，不可点）。
   - **从未生成**：单个居中按钮【开始给简历瘦身】（主色）。
   - **已生成，返回首页**：并排双按钮【重新给当前简历瘦身】（主色）+【继续给当前简历瘦身】（次色）。
4. **新建任务入口**：
   - 已生成状态下，首页底部出现文字链【＋ 新的简历瘦身】；所有页面顶栏出现【新建简历瘦身】。
   - 点击触发二次确认弹窗，确认后清空当前缓存，解锁输入框，并将按钮恢复为【开始给简历瘦身】。底部按钮变为【↺ 载入上一份简历】/【↺ 载入上一份 JD】供快捷回填。
5. **「为什么选 TrueFit？」区块**：底部展示 LLM 对比表 + 三案例卡片。

## 3. 瘦身配置弹窗

**布局**：居中弹窗，包含四个区块。
1. **打分维度**：技能 / 内容 / 行业 / 资历。默认全勾选，勾选可用，取消置灰。
2. **预设系列**：【通用】【技术】【管理】【校招】【科研】【用户自定义】。默认落在「通用」。一旦手动调参，自动切为「用户自定义」。
3. **颗粒度（单选框）**：
   - **句子**（原句溯源，耗时约90秒）
   - **句组**（智能重组，按动作分条陈列，更贴合简历格式，耗时约2分钟）—— **默认选中**
   - **段落**（大段压缩，耗时约50秒）
4. **AI分组**：启用AI自动分组（开关）。

## 4. 第2步：提取相关履历（加载等待页）

一次性加载页，全屏展示处理进度。

**布局元素：**
- **顶栏**：Logo「正在提取相关履历」+ 使用帮助 + 📊 查看匹配报告 + ← 返回首页。
- **标题**：「正在提取相关履历…」（带省略号动画）。
- **进度条**：进度条 + 百分比 + 剩余时间 ETA（「大概还剩：约 X 分钟」）。
- **4步可视化**：第1步：读取简历 / 第2步：读取职位要求 / 第3步：分析匹配度 / 第4步：整理相关经历。
- **处理日志**：📋 滚动日志区，实时输出 pipeline 日志。

**回溯模式（已完成状态下进入）：**
- 标题变为「提取完成」，无动画。
- 顶栏按钮变为「下一步：整理我的经历 →」，点击直接跳转第3步。
- 进度条 100%，四步全打勾，日志区静止展示历史日志。

## 5. 第4步：确定核心经历（结果页）

**布局**：上方两栏（左原文 : 右瘦身 = 1 : 3），各自独立滚动，栏头 sticky 吸顶。

### 5.1 左栏：简历原文（只读与精准溯源）
- 鼠标悬停有对应句组的原文，精准高亮。
- **未采用的内容**：对于被系统判定为废话并过滤的原文句子，整体文字变浅灰色，并在行内紧贴文字展示一个极小的浅灰标签 `(未采用)`，与正常黑字无缝衔接，不另起一行。

### 5.2 右栏：瘦身简历（卡片级编辑与添加）
- **顶部固定栏**：【＋ 添加经历】、【↺ 全部重置编辑】、【⬇ 导出】。
- **卡片内部**：按句组（bulletins）分条展示，每一条均可拖拽排序、删除。
- **两级添加功能**：
  - 顶部栏点击【＋ 添加经历】，在列表最前方插入一个空白经历卡片。
  - 卡片内部末尾点击【＋ 添加一条要点】，在该卡片末尾新增一条可编辑的空白 bullet。
- **标签标识系统**：
  - 原有的 AI 内容被改动：打上琥珀色标签 `✏️ 用户修改`。
  - 手动新增的经历或要点：打上蓝色标签 `✨ 用户添加`。且此类内容不绑定 `data-src`，不触发左侧原文高亮。
- **重置与容错**：重置编辑只恢复 AI 原稿，绝对不删除 `custom_` 开头的用户原创内容。

### 5.3 匹配报告（下拉抽屉）
顶栏【📊 查看匹配报告】触发展开，包含：总体匹配分、一句话结论、四维度分数、命中项、缺口项、改动说明（按 operation 分组）、补充建议。

## 6. 第3步：整理我的经历

**顶部工具栏**：
```
[☑ 全选] [计数 N/M]  [🔗 合并]                     [打散经历] [AI自动分组]
```
- **【打散经历】**：纯前端拆回“每段一卡”。已是初始态时禁用。点击带二次确认「是否要将当前的经历分组重新打散？」。
- **【AI自动分组】**：文案固定，永不置灰。点击带二次确认。一律走后端 `/api/upload(auto_cluster=true)`，由指纹缓存决定读缓存或跑 LLM。

**卡片列表**：
- 显示经历标题、相关度分、层级、关键信息。
- 支持勾选、删除（进回收站）、拖拽排序、合并（拖拽合并/勾选合并）。
- **一键生成**走自动聚类，**自己生成**走手动聚类。

## 7. 第5步：确定其他信息

**布局**：左栏原文（只读），右栏其他信息卡片（可编辑）。

- **模块**：基本信息 / 求职意向 / 教育经历 / 技能清单（相关/其他/软技能）。
- **编辑**：卡片级【✎ 编辑 / ✓ 完成】、【↺ 重置编辑】、【🗑 删除】。支持新增自定义字段、拖拽微调。
- **【＋ 新建信息板】**：可插入空白板或模板板。
- **已删除恢复条**：显示被删除的卡片，带【清空】二次确认。

---

## 8. 第6步：完成（导出与排版）

**三栏布局**：左导航（可收起）、中简历纸、右操作说明（可收起）。

- **⚙ 调整**：支持设置标题对齐（居中/居左）、大小（14-24）、正文大小（12-18）、模块分隔（有无横线）。
- **👁 审阅**：支持【页内预览】（其余界面隐为底色，无缩放）与【全屏预览】（Fullscreen API）。
- **分页逻辑**：物理分页，卡片不跨页。标题不孤行。

**⬇ 导出 菜单（5个选项）**：
1. 导出为 PDF（默认，带水印）
2. **导出为 PDF（无水印）** 👑（会员功能，Mock 阶段直接放行）
3. **导出为 Word 文档** 👑（会员功能，点击后打开新标签页展示预览，并可在页面内点击下载 `.docx`）
4. 导出为 纯文本
5. 导出到 剪切板

## 9. 异常与边界处理

| 场景 | 处理 |
|---|---|
| 简历/JD 未传完 | 生成按钮禁用 + 琥珀色文字提示缺输入 |
| 仅打开弹窗未操作 | 不算配置变更 |
| 人工编辑后溯源 | 编辑句解除 source 映射，打上 `✏️ 用户修改` |
| 输入权重越界 | 数字框钳制在 0–100 |
| 被 omit 的经历 | 不渲染于中栏，但数据层保留，支持恢复 |
| 后端不可用 | 回退内置示例数据，Toast 提示 |
| 一键生成等待期间点返回首页 | 取消任务，回首页（双保险：seq 序号比对） |
| 当前已是每段独立 | 打散分组按钮禁用，悬停提示「当前已是初始状态」 |

## 10. 状态与数据持久化

- **存储键**：`tf-live-home-v1`（sessionStorage）。
- **任何改变状态的操作都触发保存**。
- **刷新或返回首页自动恢复**：上传卡片状态、配置、各步骤编辑进度。
