### 输出层：组装完整简历

**问题：**

当前输出只有"改写后的经历"，用户还得自己拼基本信息、教育经历、技能清单，才能投递。

**目标：**

输出一份可直接投递的完整简历。

**输出结构：**

```
完整简历
├─ 基本信息（原文照搬）
├─ 求职意向（原文照搬，可选）
├─ 教育经历（原文照搬）
├─ 技能清单（按 JD 相关性排序，不删）
├─ 核心经历（调用5改写后）
├─ 相关经历（调用5改写后）
└─ 其他经历（调用5改写后）
```

**数据来源：**

| 字段 | 来源 |
|---|---|
| 基本信息 | 调用1产物的 basic_info |
| 求职意向 | 调用1产物的 intent |
| 教育经历 | 调用1产物的 education |
| 技能清单 | 调用1产物的 skills_declared，按 JD 排序 |
| 经历 | 调用5改写后的输出 |

**组装方式：** 纯规则拼接，不调 LLM。

**技能排序规则：**
- JD 里出现的技能 → 排前面
- JD 里没出现的 → 排后面
- 不删任何技能

**为什么不用 LLM：**

调用1 已经提取了这些字段，直接取即可。
